ONI3 Web API

oni3 web 同时提供浏览器界面、Web API、AG-UI、A2A 和 MCP Server。所有端点与界面共用同一套 Agent、模型、工具、审批和会话数据。

用 --web、--agui、--a2a、--mcp 控制各端点，默认全部开启。例如 oni3 serve --web=false --agui=false --a2a=false --mcp 只启动 MCP Server；此时浏览器界面、Web API、登录页和本文档均不可用，但 /api/health 仍可访问。四个开关至少要保留一个。

认证

未设置 --token 或 ONI3_WEB_TOKEN 时无需认证。启用后，除登录页和登录接口外，所有端点都需要认证：

Authorization: Bearer $ONI3_WEB_TOKEN
X-Oni3-Token: $ONI3_WEB_TOKEN
?token=$ONI3_WEB_TOKEN

浏览器登录成功后使用 HttpOnly Cookie；API 客户端建议使用 Bearer Token。跨域浏览器请求会被拒绝。

POST/api/login
请求体 {"token":"..."}。成功返回 204 并设置 HttpOnly Cookie。
POST/api/logout
清除登录 Cookie，返回 204。
GET/api/auth
已认证时返回 {"authenticated":true}，供页面恢复登录状态。

Web API

GET/api/bootstrap
返回默认 Agent、Agent 列表、模型别名、工作目录、版本和认证状态，供前端初始化。
GET/api/agents
返回 Agent 名称、描述和默认模型，格式为 {"agents":[...]}。
GET/api/models
返回模型别名列表和 default_model。
GET/api/sessions?limit=40&q=keyword
列出最近会话。q 可选，搜索标题、Agent、模型、会话 ID 和消息内容；搜索时覆盖全部本地会话，结果仍受 limit 限制。
GET/api/sessions/{id}
返回单个会话摘要和完整事件历史，用于恢复对话。
POST/api/chat
发送一轮消息，返回 text/event-stream。请求体：
{
  "agent": "search_agent",
  "prompt": "搜索今天的新闻",
  "model": "optional_model_alias",
  "session_id": "optional_existing_session"
}
POST/api/respond
回答 ask_user 提问或工具审批。审批：{"id":"...","approved":true,"remember":false}；提问：{"id":"...","value":"answer"}。
POST/api/cancel
停止运行中的会话。请求体：{"session_id":"..."}。
GET/api/health
健康检查，返回 {"status":"ok"}。

聊天事件

/api/chat 的 SSE 数据行是 JSON，主要事件类型：

  • session：会话 ID。
  • content：增量回答文本。
  • reasoning：增量推理文本。
  • tool：工具调用开始或结束。
  • todos：任务列表更新。
  • question：Agent 等待用户回答，通过 /api/respond 继续。
  • approval：工具调用等待审批，通过 /api/respond 继续。
  • error：本轮错误。
  • done：本轮结束，包含停止原因。

AG-UI

POST/agui
接收 AG-UI RunAgentInput，返回 text/event-stream。可用 forwardedProps.agent 与 forwardedProps.model 选择 Agent 和模型。
POST/agents/{agent}/agui
指定 Agent 的 AG-UI 便捷端点。使用 --agui=false 可关闭。

A2A

GET/.well-known/agent-card.json
默认 Agent 的 A2A Agent Card。
GET/agents/{agent}/.well-known/agent-card.json
指定 Agent 的 Agent Card。
POST/a2a
A2A 1.0 JSON-RPC：SendMessage、SendStreamingMessage、GetTask、ListTasks、CancelTask、SubscribeToTask，同时兼容 0.3 斜杠方法名。消息角色使用 ROLE_USER / ROLE_AGENT，也接受 0.3 的 user / agent。
POST/agents/{agent}/a2a
指定 Agent 的 A2A JSON-RPC 端点。使用 --a2a=false 可关闭。

MCP Server

这里把 Oni3 本身作为 MCP Server，通过 HTTP 向 MCP 客户端暴露工具，而不是管理 config.yml 中的外部 mcp_servers。Web 服务复用 oni3 mcp 的三个工具：

  • call_agent(agent, prompt, model?)
  • list_agents()
  • list_models()
POST/mcp
MCP Server 的 Streamable HTTP 主端点，接收 JSON-RPC。客户端配置示例：
{
  "mcpServers": {
    "oni3": {
      "url": "http://127.0.0.1:8080/mcp",
      "headers": { "Authorization": "Bearer $ONI3_WEB_TOKEN" }
    }
  }
}
GET/mcp
Streamable HTTP 的服务端通知流。
GET/mcp/sse
兼容旧版 MCP SSE 传输，服务端通过 SSE 下发消息端点 /mcp/message?sessionId=...。
POST/mcp/message?sessionId=...
旧版 SSE 传输的客户端消息入口。使用 --mcp=false 可关闭 MCP Server 端点。
启动时会打印已启用的 Web、AG-UI、A2A 和 MCP 地址。所有协议都受与 Web 页面相同的 Token 认证保护。
